# Learn SecByte CTF Labs: Git, SSH, SQL Injection, SQLMap & Meterpreter

A focused collection of Learn SecByte CTF and hands-on cybersecurity labs covering Git security, SSH-related scenarios, hidden repositories, SQL injection, SQLMap, DarkHole, Leaky Vault, and Meterpreter.

This repository is designed as a searchable learning index for cybersecurity students, CTF players, ethical hacking learners, penetration testers, SOC analysts, and security enthusiasts working in authorized lab environments.

## Introduction

The collection brings together practical cybersecurity labs identified by the supplied Learn SecByte URLs.

The URLs indicate several recurring themes:

- Git and hidden repository security
- Git-to-SSH access and pivoting
- SQL injection (SQLi)
- SQLMap
- DarkHole-related labs
- Hidden data and repository discovery
- Meterpreter
- Web security and vulnerability testing

The linked labs should be used only in authorized environments.

## Learning Path

A practical learning sequence is:

1. Begin with **Dark Repository Hunt** and the Git-focused labs.
2. Explore **GitGhost** and **GitShadow** scenarios.
3. Continue with the **Git-to-SSH** and SSH pivoting labs.
4. Study the SQL injection labs, including **GitTrail SQLi**.
5. Explore **SQLMap Shadow Dive** to study the SQLMap-focused scenario.
6. Continue with the DarkHole-related injection and SQLi labs.
7. Finish with **Meterpreter Matrix** for the collection's post-exploitation-focused exercise.

Difficulty levels are not specified by the supplied URLs, so this repository does not assign difficulty ratings.

## How to Use the Labs

1. Select a lab from the direct index.
2. Open the corresponding Learn SecByte resource.
3. Follow its documented setup and learning requirements.
4. Work only against the authorized CTF/lab target.
5. Document the security concepts you encounter.
6. Practice detection, remediation, and defensive understanding alongside offensive techniques.
7. Never test systems without explicit authorization.
